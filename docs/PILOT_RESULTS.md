# Что проверено в пилоте

[English](PILOT_RESULTS.en.md) · [中文](../i18n/zh/PILOT_RESULTS.md) · [Español](../i18n/es/PILOT_RESULTS.md) · [Français](../i18n/fr/PILOT_RESULTS.md) · [Deutsch](../i18n/de/PILOT_RESULTS.md) · [Italiano](../i18n/it/PILOT_RESULTS.md) · **Русский** · [Português](../i18n/pt/PILOT_RESULTS.md) · [العربية](../i18n/ar/PILOT_RESULTS.md)

До выбора архитектуры без координаторов проект собрал **доверенный пилот** с центральным сервером
и несколько исследовательских прототипов проверки. Ниже то, что было реально запущено и измерено,
и где проходят границы этих результатов. Исходный код пилота в этот репозиторий не входит.

Пилот — это закрытая система с доверенным оператором. Он не защищён от обмана в открытой сети
и не реализует целевую архитектуру. Все выплаты в нём учебные (TEST_CREDIT, без вывода).

## Инференс и учёт

| Что | Результат |
|---|---|
| Серверный контур | API, очередь, PostgreSQL, агент, отдельная проверка результата и учебное начисление в одной транзакции. Повторная отправка не даёт второго начисления, устаревшая аренда задания отвергается |
| Слабая GPU | Qwen2.5-0.5B-Instruct Q4_K_M через llama.cpp (Vulkan) на встроенной Intel Arrow Lake-P: принятое задание, отклонённая подмена ответа |
| Вторая GPU | Qwen3-4B-Instruct-2507 Q4_K_M на RTX 2060 6 ГБ: все слои на GPU, около 2,4 ГиБ VRAM, медиана 73,8 токена/с на коротком профиле |
| Модель на нескольких компьютерах | Слои Qwen3-4B распределялись по локальной сети между RTX 2060 и GPU участника (RTX 4070 Laptop, затем Intel Arrow Lake-P). Участник получал только назначенную часть весов в память. Пара RTX 2060 + RTX 4070 Laptop дала около 38–40 токенов/с против 69,5 на одной RTX 2060: дополнительная память не гарантирует ускорения |
| Восстановление | Пауза, возобновление и автоматическое восстановление группы после обрыва туннеля |

Проверка в пилоте — повтор генерации на **том же доверенном** GPU. Это не доказательство честности
незнакомого узла.

## Прототипы проверки вычислений

| Что | Результат | Граница |
|---|---|---|
| Groth16 для двух целочисленных matmul + Solidity verifier | Настоящие доказательства и однократная выплата в локальной EVM | Маленькая задача на CPU |
| RISC Zero для одной строки Q4_K проекции Qwen на реальных данных | Доказательство 22 мин 10 с, проверка 117 мс, входы 11,7 КБ | Одна строка, не весь граф; далеко за бюджетом |
| Пакет из восьми строк в zkVM | 350 мс исполнения против 19,8 мкс нативно (~17 700×) | Без построения доказательства |
| Cartesi: спор о результате Qwen | Подмена одного бита найдена; спор 93 транзакции, 5,8–6,3 млн gas | Требует своевременного честного оспаривающего |
| Полный повтор арифметики строки в EVM | 14,1 млн gas за подачу | Одна строка |
| Автоматические аудиторы | Сторонний аудитор опроверг ложный вектор вопреки двум согласившимся | Без наблюдателя ошибка прошла по оптимистическому правилу |
| Сговор исполнителя и проверяющего | Получили выплату за неверный результат | Показывает, почему голосование проверяющих не гарантия |

## Чего не было

- Распределённого обучения.
- Жёстких аппаратных квот CPU/GPU/RAM/VRAM.
- Реальных денежных выплат.
- Проверки на независимом оборудовании в открытой сети.
- Измерения энергии.
- Экспериментов по новой архитектуре без координаторов: она пока только спроектирована.
