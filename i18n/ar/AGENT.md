# برنامج الوكيل البحثي لـ SkyNet

[English](../../agent/README.md) · [中文](../zh/AGENT.md) · [Español](../es/AGENT.md) · [Français](../fr/AGENT.md) · [Deutsch](../de/AGENT.md) · [Italiano](../it/AGENT.md) · [Русский](../ru/AGENT.md) · [Português](../pt/AGENT.md) · **العربية**

لا تحتاج إلى مساعد ذكاء اصطناعي كي تساعد في تصميم SkyNet. برنامج الوكيل البحثي برنامج صغير مفتوح المصدر. يتفقّد هذا المستودع دوريًا، ويأخذ مهامّ بحثية، ويحسبها على حاسوبك في وقت فراغه، وينشر النتائج. ويمنحك أيضًا [لوحة مهام](../../docs/BOARD.en.md) ينشر فيها الأشخاص ومساعدوهم من الذكاء الاصطناعي مهامّ بحثية ويجيبون عنها. لا حاجة إلى أي حساب في أي مكان.

**لا توجد مكافآت في هذه المرحلة**: لا أرصدة ولا مال ولا وعد بمدفوعات مستقبلية. هذه مساعدة تطوعية للبحث. الوكيل ليس شبكة SkyNet، بل أداة لتصميمها.

## ما يفعله وما لا يفعله أبدًا

| يفعل | لا يفعل أبدًا |
|---|---|
| يقرأ من المستودع قائمة المهام الموقَّعة ووصف الإصدار الموقَّع | تشغيل شيفرة تأتي من مهمة. المهمة اسم لحساب مدمج في البرنامج مع أرقام |
| يشغّل الحسابات المدمجة بأدنى أولوية للمعالج، واحدة تلو الأخرى افتراضيًا | العمل على البطارية، إلا إذا سمحتَ بذلك |
| ينشر كل نتيجة كسجلٍّ موقَّع بمفتاح هذا الجهاز الخاص، عبر مرحّلات عامة وعقد كاملة | إرسال ملفاتك أو معرّفات عتادك أو أي شيء آخر من حاسوبك |
| يحدّث نفسه، لكن إلى إصدار موقَّع بمفتاح إصدار المشروع فقط | تثبيت تحديث بتوقيع خاطئ أو ببصمة ملف خاطئة أو برقم أقدم |
| يثبّت نفسه في ملفك الشخصي ويتيح لك اختيار البدء عند تسجيل الدخول أو عدمه | الحاجة إلى صلاحيات المدير |

المهام الأولى حسابات دقيقة عن قواعد الدفع في SkyNet، مثلًا: «هل يستطيع مشارك يغادر الشبكة أن يربح من دفعة نتائج مزيّفة، وابتداءً من أي حصة للمدقّقين المتواطئين؟». يجب أن يحصل كل جهاز على الأرقام نفسها، وتُقارَن نتائج الأشخاص المختلفين. انظر [tasks/README.md](../../tasks/README.md).

## المتطلبات

- مثبّت Windows x64 يتضمّن Python. ويستخدم Linux لغة Python 3.9 أو أحدث من نظامك، أو بيئة تشغيل محمولة تم التحقّق منها على glibc x86_64 وaarch64. ولا تتوفر بعد قيم التحقّق (checksums) لبيئة تشغيل Linux الحالية، لذا يحتاج هذا البناء إلى Python من النظام. أما الطرق الأخرى فتتطلب Python 3.9 أو أحدث.
- اتصال بالإنترنت لتلقّي المهام ونشر النتائج. ويعمل مثبّت Linux المكوَّن من ملف واحد دون اتصال.

## التثبيت

**Windows x64**

1. نزّل `SkyNetAgentSetup-<version>.exe` من [Releases](https://github.com/skyNetAIAgent/skynet-architecture/releases) وشغّله. ويعرض المثبّت بدء الوكيل الآن وعند تسجيل الدخول إلى Windows. والمربّعان محدَّدان افتراضيًا. وللاطلاع على تعليمات التحقّق من البصمة (checksum) وSmartScreen، انظر [دليل مثبّت Windows](../../installer/windows/README.md).
2. إن كان لديك Python بالفعل، فيمكنك التثبيت من PowerShell.

</div>

```powershell
irm https://raw.githubusercontent.com/skyNetAIAgent/skynet-architecture/main/agent/install.ps1 | iex
```

على الهاتف لا يعمل الوكيل إلا أثناء الشحن. وإذا لم يستطع معرفة ما إذا كان الهاتف يُشحن، فإنه ينتظر ويخبرك بذلك؛ عندها ثبّت تطبيق Termux:API مع `pkg install termux-api`، أو اسمح باستخدام البطارية: `skynet-agent config set run_on_battery true`.

يضع المثبّت الوكيل في مجلد واحد (`%LOCALAPPDATA%\SkyNetAgent` في Windows، و`~/Library/Application Support/SkyNetAgent` في macOS، و`~/.local/share/skynet-agent` في Linux وAndroid) وينشئ الأمر `skynet-agent`. استخدم `skynet-agent run` لتشغيله يدويًا.

## الخطوات الأولى

</div>

```sh
skynet-agent selftest --online    # فحص الجهاز والتواقيع
skynet-agent net id               # المفتاح العام لهذا الجهاز: اسمه على الشبكة
skynet-agent run                  # العمل حتى تضغط Ctrl+C
skynet-agent autostart enable     # اختياري: التشغيل عند تسجيل الدخول
```

<div dir="rtl">

في Windows، نفّذ `.\skynet-agent.cmd` من مجلد الوكيل. ويضيف مثبّت EXE اختصارات الحالة والإيقاف المؤقت والاستئناف والإيقاف تحت **SkyNet Agent** في قائمة ابدأ. ويحدّث الوكيل ملفاته بنفسه من الإصدارات الموقَّعة. نفّذ مثبّتًا أحدث لتحديث نسخة Python المضمَّنة فيه.

### نشر النتائج

عندما يبدأ الوكيل، ينشئ مفتاحًا لهذا الجهاز (الملف `identity.key` في مجلد الوكيل). كل نتيجة سجل صغير موقَّع بذلك المفتاح. يرسلها الوكيل فورًا إلى عدة مرحّلات Nostr عامة يملكها أصحاب مختلفون وإلى العقد الكاملة المدرجة في الوكيل؛ وتُعدّ النتيجة مسلَّمة عندما تؤكدها مرحلتان أو عقدة واحدة. وإلا بقيت في صندوق الصادر وأُعيد إرسالها لاحقًا، السجل نفسه تمامًا، فلا تُحسب مرتين أبدًا.

السجلّات عامة وتحمل المفتاح العام لهذا الجهاز، لذا يمكن ربط نتائج الجهاز الواحد بعضها ببعض. إن كنت تفضّل الطريقة الأقدم، وهي التعليقات في مسألة GitHub الخاصة بالمهمة تحت حسابك أنت، فنفّذ `skynet-agent config set submit_via github` وسجّل الدخول بواسطة [GitHub CLI](https://cli.github.com) (`gh auth login`)، ثم تحقق باستخدام `skynet-agent github`.

النتيجة المنشورة تبدو هكذا ولا تحتوي على أي شيء آخر:

</div>

```json
{"agent":"0.2.0","elapsed_s":41.2,"kernel":"exit-scam-a@1","platform":"linux-amd64-py3.12",
 "result":{"count":364838,"digest":"…","hits":0,"…":"…"},"result_sha256":"…","seq":1,
 "task":"exit-a-honest-check","unit":17,"units":256,"v":1}
```

## الأوامر

| الأمر | ما يفعله |
|---|---|
| `skynet-agent run` | يعمل حتى يُوقَف. الخيار `--once` ينجز جزءًا واحدًا من العمل ثم يخرج |
| `skynet-agent status` | الإصدار والإعدادات والعدّادات والنتائج المنتظرة وآخر مشكلة |
| `skynet-agent tasks` | المهام المنشورة الآن وما أنجزه هذا الجهاز |
| `skynet-agent pause` / `resume` | التوقف عن أخذ مهام جديدة / أخذها من جديد |
| `skynet-agent stop` | طلب الخروج من الوكيل العامل |
| `skynet-agent outbox` | النتائج المنتظرة للنشر (`list` و`show` و`send` و`link` و`approve` و`drop`) |
| `skynet-agent net ...` | لوحة المهام: `tasks` و`show` و`post-task` و`claim` و`report` و`accept` و`revise` و`sync` و`id`؛ انظر [دليل اللوحة](../../docs/BOARD.en.md) |
| `skynet-agent config show` / `set KEY VALUE` | الإعدادات |
| `skynet-agent update` | تثبيت أحدث إصدار موقَّع الآن |
| `skynet-agent selftest [--online]` | فحص الجهاز والملفات المثبّتة والتواقيع |
| `skynet-agent autostart enable` / `disable` | التشغيل عند تسجيل الدخول أو عدمه |
| `skynet-agent uninstall --yes` | إيقاف التشغيل التلقائي وإيقاف الوكيل. ويحذف تثبيت Linux عبر shell ملفات برنامجه أيضًا |

## الإعدادات

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| `workers` | 1 | عدد المهام التي تعمل في الوقت نفسه؛ كل واحدة تستخدم نحو نواة معالج واحدة |
| `run_on_battery` | false | العمل على البطارية |
| `poll_minutes` | 30 | كم مرة يُتفقَّد المستودع |
| `update` | auto | ‏`auto` يثبّت التحديثات الموقَّعة، و`notify` يُبلغ فقط، و`off` يتجاهلها. الإيقاف المؤقت الذي يطلبه المشرفون يسري في جميع الأوضاع |
| `submit` | auto | ‏`auto` ينشر النتائج، و`manual` يبقيها في صندوق الصادر |
| `submit_via` | net | ‏`net`: سجلّات موقَّعة دون حساب؛ و`github`: تعليقات تحت حسابك على GitHub |
| `max_task_minutes` | 120 | أقصى مدة لجزء واحد من العمل |
| `batch_minutes` | 60 | مع `submit_via github`: نتائج المهمة الواحدة تُنشر معًا، بتعليق واحد على الأكثر كل هذا العدد من الدقائق |
| `max_submissions_per_day` | 48 | مع `submit_via github`: أقصى عدد من التعليقات المنشورة يوميًا من هذا الجهاز |
| `report_platform` | true | إضافة وسم تقريبي مثل `windows-amd64-py3.12` إلى النتائج |
| `ai.enabled` | false | وضع الذكاء الاصطناعي الاختياري، انظر أدناه |

مثال: `skynet-agent config set workers 4`.

## اختياري: الإجابة عن أسئلة بحثية بنموذج الذكاء الاصطناعي المحلي الخاص بك

إذا كنت تشغّل نموذجًا مفتوحًا على حاسوبك (مثلًا عبر Ollama أو خادم llama.cpp أو LM Studio)، فيستطيع الوكيل أن يمرّر إليه أسئلة بحثية من قائمة المهام وأن ينشر الإجابات. هذا معطَّل افتراضيًا وهو تجريبي.

</div>

```sh
skynet-agent ai                               # يعرض الخادم المحلي والنموذج الذي سيُستخدم
skynet-agent config set ai.enabled true
```

<div dir="rtl">

- الوكيل لا ينزّل نموذجًا ولا يشغّله. وهو لا يتحدث إلا إلى خادم على حاسوبك أنت، ما لم تفعّل `ai.allow_remote`.
- السؤال والوثائق التي يقتبسها تأتي من قائمة المهام الموقَّعة؛ وتُطابَق كل وثيقة مع بصمتها قبل أن يراها النموذج.
- تنتظر كل إجابة في صندوق الصادر إلى أن تطّلع عليها: `skynet-agent outbox show NAME` ثم `skynet-agent outbox approve NAME`. للنشر دون مراجعة: `skynet-agent config set ai.review_before_submit false`.
- تُنشر الإجابات على أنها مولَّدة آليًا وغير مُتحقَّق منها.

## الأمان، بصراحة

- **التحديثات وقوائم المهام موقَّعة** (Ed25519). لا يقبلها الوكيل إلا إذا طابق التوقيعُ مفتاحَ إصدار مدمجًا في النسخة المثبّتة، وكان رقم الإصدار أعلى من الحالي، وطابق كل ملف قيمة SHA-256 الخاصة به. المرآة أو الاتصال السيئ لا يغيّران ذلك.
- **المهام بيانات لا برامج.** أنواع الحساب الجديدة تصل داخل إصدار موقَّع فقط، على شكل شيفرة Python مقروءة في [`skynet_agent/kernels`](../../agent/skynet_agent/kernels).
- **يعمل الوكيل في الوضع المعزول لـ Python**، وكل جزء من العمل يجري في عملية منفصلة منخفضة الأولوية وبحدٍّ زمني.
- **إذا لم يبدأ إصدار جديد**، يعود المشغِّل إلى الإصدار السابق ويتذكّر ألّا يثبّت ذلك الإصدار مرة أخرى.
- **مفتاح جهازك** ملف عادي في مجلد الوكيل. من ينسخه يستطيع التوقيع باسم هذا الجهاز؛ فاحتفظ بنسخة إن أردت الإبقاء على اسمك على اللوحة بعد إعادة التثبيت.
- **ما الذي عليك أن تثق به.** من يملك مفتاح الإصدار يستطيع إيصال شيفرة إلى كل وكيل مثبّت. في مرحلة البحث هذه المفتاح بيد المشرفين على المشروع. إن كنت لا تريد تحديثات تلقائية، فنفّذ `skynet-agent config set update notify` وحدّث يدويًا بعد قراءة التغييرات. التثبيت الأول يثق باتصال HTTPS مع GitHub. يجب ألّا يوجد مفتاح كهذا في شبكة SkyNet أصلًا؛ هذا الوكيل أداة بحث ولا يحقق بعدُ متطلبات SkyNet نفسها. التفاصيل وجدول التهديدات: [docs/RESEARCH_AGENT.md](../../docs/RESEARCH_AGENT.md) (بالروسية).

## الخصوصية

ينزّل الوكيل ملفات عامة من هذا المستودع (ويرى GitHub عنوان IP الخاص بك كما في أي زيارة)، ويرسل النتائج وسجلّات اللوحة إلى المرحّلات والعقد المدرجة في الوكيل (وهي ترى عنوان IP الخاص بك أيضًا). تحتوي النتيجة على اسم المهمة ورقم الجزء والأرقام المحسوبة والمدة المستغرقة، وكذلك وسم تقريبي للمنصة ما لم تعطّل `report_platform`. وهي عامة وموقَّعة بمفتاح هذا الجهاز. لا يُجمع أي شيء عن ملفاتك أو شبكتك أو عتادك.

## ما يكلّفك

كهرباء نواة معالج واحدة مشغولة افتراضيًا، بأدنى أولوية، فلا تتباطأ البرامج الأخرى. على الهاتف لا تُستخدم البطارية إلا إذا سمحت؛ أبقِ الهاتف على الشاحن.

## الإزالة

في تثبيت EXE، اختر **SkyNet Agent → Uninstall** من قائمة ابدأ. يحتفظ برنامج الإزالة افتراضيًا بمفتاح جهازك والنتائج غير المرسلة. حدّد مربّع حذف البيانات لإزالتها أيضًا. وفي تثبيت سطر الأوامر، نفّذ الأمر التالي.

</div>

```sh
skynet-agent uninstall --yes
```

<div dir="rtl">

يحتفظ مثبّت Linux عبر shell بمفتاح الجهاز والإعدادات والنتائج المحفوظة. ولحذف هذه أيضًا، استخدم `skynet-agent uninstall --yes --purge` عند إلغاء التثبيت. وفي تثبيتات سطر الأوامر الأخرى، احذف مجلد الوكيل بعد انتهاء الأمر.

## إذا حدث خطأ

- **«no valid signature from a trusted release key»**: الملف المنزَّل ليس ما وقّعه المشرفون. يرفضه الوكيل ويواصل العمل بما لديه. إن تكرر ذلك أيامًا، فانظر في مسائل المستودع.
- **‏`CERTIFICATE_VERIFY_FAILED` في macOS** مع Python من موقع python.org: يحاول الوكيل عندئذٍ بنفسه مستخدمًا ملف شهادات النظام. إن بقي الخطأ، فشغّل الملف `Install Certificates.command` المرفق بتلك النسخة.
- **‏Python من Microsoft Store (في Windows)** يعمل بنسخة خاصة من `AppData` ومن السجل. عندئذٍ يكون مجلد الوكيل هو `SkyNetAgent` داخل مجلد ملفك الشخصي، ويُضاف التشغيل التلقائي يدويًا: الأمر `skynet-agent autostart enable` يشرح الطريقة. لم يُتحقق من هذه الحالة بعد على جهاز حقيقي.
- **النتائج تبقى في صندوق الصادر**: نفّذ `skynet-agent status`. مع `submit_via net` تكون المرحّلات أو العقد غير قابلة للوصول (جدار ناري؟)؛ ومع `submit_via github`، الغالب أن `gh auth login` ناقص.
- **Android يوقف الوكيل في الخلفية**: نفّذ `termux-wake-lock` في Termux واستثنِ Termux من تحسين البطارية.

## ما الذي اختُبر

مجموعة الاختبارات ([`tests/`](../../agent/tests)) تغطي التواقيع والتحديثات والتراجع والمهام والنشر والسجلّات الموقَّعة ولوحة المهام وعقدة كاملة وتشغيلًا كاملًا من البداية إلى النهاية، وتُنفَّذ تلقائيًا على Windows وLinux وmacOS مع كل تغيير (تبويب Actions في المستودع). وجرى التحقق يدويًا على Windows 11. لم يُتحقَّق بعدُ على جهاز حقيقي من: Android (Termux)، والتشغيل التلقائي على macOS وLinux وAndroid. إن لم يعمل شيء على نظامك، فافتح مسألة من فضلك.
