# كيف تساهم

[English](../../CONTRIBUTING.md) · [中文](../zh/CONTRIBUTING.md) · [Español](../es/CONTRIBUTING.md) · [Français](../fr/CONTRIBUTING.md) · [Deutsch](../de/CONTRIBUTING.md) · [Italiano](../it/CONTRIBUTING.md) · [Русский](../ru/CONTRIBUTING.md) · [Português](../pt/CONTRIBUTING.md) · **العربية**

شكرًا لرغبتك في المساعدة. ما يهم هنا هو الدقة لا الحجم: ثغرة واحدة مكتشفة مع سيناريو ملموس أثمن من عشر صفحات من التأملات العامة.

## ماذا تقدّم

- **هجومًا على التصميم الحالي.** سيناريو: من يتصرّف، وماذا يفعل، وماذا يكسب، ولماذا لا تلاحظ الشبكة ذلك. اذكر القسم من [CURRENT_DESIGN](../../docs/CURRENT_DESIGN.md).
- **حلًّا لإحدى [المسائل المفتوحة](../../docs/OPEN_QUESTIONS.en.md).**
- **مصدرًا**: ورقة بحثية أو بروتوكولًا أو مشروعًا يحلّ جزءًا من مسألة، مع الإصدار والتاريخ وما **لا** يثبته بالنسبة لحالتنا.
- **حسابًا للتكلفة** أو تصحيحًا لحساب قائم.
- **تصحيحًا للترجمة**: عدم دقة في ترجمة الأساس (عبر ملف التصويبات).
- **مهمة لبرنامج الوكيل البحثي**: حسابًا يجيب عن جزء من مسألة مفتوحة (انظر [tasks/README.md](../../tasks/README.md)).
- **قدرة حاسوبية**: إن لم يكن لديك مساعد ذكاء اصطناعي ولا وقت للكتابة، فشغّل [برنامج الوكيل البحثي](AGENT.md) على حاسوبك أو هاتفك.

## كيف تقدّمها

افتح issue وابدأ العنوان بوسم:

| الوسم | لأجل |
|---|---|
| `[Attack]` | طريقة لخداع الشبكة أو تعطيلها |
| `[Q<N>]` | اقتراح للمسألة المفتوحة رقم N |
| `[Source]` | ورقة بحثية أو مشروع مفيد |
| `[Cost]` | تقدير للتكلفة أو تصحيح للأرقام |
| `[Translation]` | عدم دقة في الترجمة |
| `[Task]` | حساب لبرنامج الوكيل البحثي |

اذكر في النص:

1. ما المضمون وبأي افتراضات.
2. الآلية.
3. الهجمات المعروفة وما يتبقى.
4. التكلفة، موسومة بـ [حساب] أو [مُقاس].
5. أي المتطلبات الستة في [المتطلبات](REQUIREMENTS.md) تحققت وأيها لم يتحقق.

طلبات pull request لوثائق العمل (`docs/`) مرحّب بها. إذا غيّرت حالة بند، فاشرح السبب. يمكن كتابة issues وpull requests بأي لغة من لغات المستودع.

## القواعد

- **الأساس لا يتغيّر.** لن يُقبل أي pull request يغيّر البيان أو المتطلبات أو README أو بصماتها. انظر [CORE.md](../../CORE.md).
- لا يُقدَّم الحساب على أنه قياس، ولا الاقتراح على أنه قرار.
- لا تنشر مفاتيح أو كلمات مرور أو بيانات شخصية أو عناوين حواسيب.
- كن مهذّبًا وفي صلب الموضوع. انتقد الأفكار لا الأشخاص.

إن كنت تعمل مع مساعد ذكاء اصطناعي، فأعطه [AGENTS.md](AGENTS.md). كاتب الـ issue مسؤول عن دقة نصّه.
