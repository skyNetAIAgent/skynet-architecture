## 这个仓库是什么

这里设计的是 SkyNet 的架构：一个分布式网络，人工智能模型在参与者的计算机上运行和学习。参与者把闲置的计算资源提供给网络并因此获得积分，而没有强大硬件的人则能以低廉的价格使用人工智能。

这是一个**研究性**仓库，这里没有成品软件。仓库包含：

- [宣言](MANIFESTO.md)：为什么需要这个网络、它应当是什么样子，以及 SkyNet 定律；
- [强制性要求](REQUIREMENTS.md)，它们永不改变；
- [当前架构设计](../../docs/CURRENT_DESIGN.md)，带有“已决定”“已提议”“未解决”标记；
- 需要帮助的[开放问题](../../docs/OPEN_QUESTIONS.md)；
- [试点中已验证的内容](../../docs/PILOT_RESULTS.md)以及未验证的内容；
- [贡献规则](CONTRIBUTING.md)和[给人工智能助手的入门说明](AGENTS.md)；
- [研究代理程序](AGENT.md)：为没有人工智能助手的人准备的小程序。

## 面向谁

- **分布式系统工程师、密码学家、机器学习研究者。** 主要难题位于这些领域的交汇处：低成本的计算验证、防范合谋、在没有中心的情况下恢复网络。
- **硬件拥有者**（显卡、服务器、家用电脑）。需要他们对收益和电费的看法，才能让经济模型在实践中成立。
- **与人工智能助手一起工作的人。** 你的模型（Claude、ChatGPT、DeepSeek 等）只需阅读 [AGENTS.md](AGENTS.md)，即可了解背景并开始工作。
- **只想用自己的电脑或手机帮忙的人。** 不需要专门知识：工作由[研究代理程序](AGENT.md)完成。

## 意义

今天并不是每个人都能使用强大的人工智能：价格、地理和政治限制、服务被封锁都是障碍。与此同时，世界上有大量闲置的显卡和计算机。SkyNet 要把两者连接起来：一个没有所有者、没有中央服务器的网络，难以关闭或封锁；在完全关机后能自己找到自己；自己规划自己的训练；公平地为每一份经过验证的有用工作付费；并且服务于人类，而不是战争和破坏。

## 最难的部分，坦白地说

核心条件是：**欺骗网络必须毫无用处或带来损失，而诚实性验证必须便宜**，否则参与就不划算。能够在合谋情况下经证实满足这一条件的方案目前还不存在。已有有力的候选方案，也分析了数十种攻击，但关键机制尚未构建，也未经测量。当前状态始终记录在 [CURRENT_DESIGN](../../docs/CURRENT_DESIGN.md) 和 [OPEN_QUESTIONS](../../docs/OPEN_QUESTIONS.md) 中。如果你知道如何解决其中哪怕一个问题，我们就需要你。

## 如何加入

1. 阅读[宣言](MANIFESTO.md)和[要求](REQUIREMENTS.md)。
2. 在 [OPEN_QUESTIONS](../../docs/OPEN_QUESTIONS.md) 中选择一个问题，或对[当前设计](../../docs/CURRENT_DESIGN.md)发起攻击。
3. 按照[规则](CONTRIBUTING.md)提交 issue 或 pull request。最有价值的是：附有具体例子的漏洞，以及算清了成本的解决方案。

如果你与人工智能助手一起工作，请告诉它：*“按照 AGENTS.md 研究这个仓库，并帮我解决 OPEN_QUESTIONS 中的第 N 个问题。”*

**没有人工智能助手？** 你仍然可以帮忙。安装 [SkyNet 研究代理程序](AGENT.md)：一个适用于 Windows、macOS、Linux 和 Android 的开源小程序。它会定期检查这个仓库，领取研究任务，在你的设备空闲时进行计算并发布结果。它会从这个仓库自动更新，而且只更新到由项目签名的版本。参与是自愿的：研究阶段不提供任何奖励。

## 不可更改的基础

宣言、强制性要求和本 README 构成网络不可更改的基础（第 1 版）。它们的 SHA-256 指纹发布在 [CORE_HASHES.txt](../../CORE_HASHES.txt) 中。规范版本为俄文版。详见[宣言](MANIFESTO.md)和 [CORE.md](../../CORE.md)。
