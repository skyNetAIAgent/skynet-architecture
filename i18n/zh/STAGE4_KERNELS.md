## 版本 1 通用规则

在待签名任务中，内核名称和整数 `kernel_version: 1` 分开存储。输入 `params` 是包含该内核所列全部字段的对象。多余和缺失的字段、重复的 JSON 键、超出范围的值以及错误的类型都会导致错误。整数以 JSON 整数字面量书写，不带小数点和指数。禁止用字符串和布尔值代替数字。边界包含端点。网格轴保持输入顺序。unit 的数量恰好等于为该内核指定的网格大小，从 1 到 1 000 000。unit 编号从零开始。在笛卡尔积中，最后一轴变化最快。

校验时取整个结果对象。在 Python 中，规范字节等于 `json.dumps(result, sort_keys=True, ensure_ascii=True, separators=(',', ':')).encode('ascii')`，不带末尾换行符。结果哈希是这些字节的 SHA-256，由 64 个小写十六进制数字组成。数组元素的顺序有意义。字符串中的分数以十进制写作 `p/q`，约分后分母为正，包括 `0/1` 和带 `/1` 的整数。没有前导加号或零。对于 M14，另行定义了打包结果*内部*字节的哈希。[代理的规范编码器](../../agent-go/canon/canon.go)

## M8. 每个参与者一次更新时 T4 的规模

`t4-scale@1` 计算每轮自身训练 token 的最小整数数量，使得考试增加的算力不超过 20%。对于给定的 token 预算，该内核还求出提交者的上限数量。在模型中，每个节点检查全部 `K=N` 个更新。基线在每个位置花费一次前向遍历，每次上层更新花费一次遍历的 `a=L_a/L` 份额，而训练一个 token 需要三次遍历。这些比例由提案给出。claude1，§5.4「成本」和 §7.5 第 4 点 · critic_claude，§1.8 和 §10.4 第 3 点 · [VERIFICATION_SEARCH, §5.3, M8](VERIFICATION_SEARCH.md)

| `params` 字段 | 允许值 |
|---|---|
| `N` | 从 1 到 1 000 000 的整数轴。轮次中的提交者数量 |
| `n` | 从 1 到 1 000 000 的整数轴。考试位置数量 |
| `a` | 整数对 `[p,q]` 的轴，其中 `1 ≤ p ≤ q ≤ 1 000 000`。每次更新的遍历份额 |
| `D_budget` | 从 1 到 1 000 000 000 000 的整数轴。每轮每个节点的训练 token 预算 |
| `epsilon_bits` | 一个从 1 到 256 的整数。为固定考试设定 `ε=1/2^epsilon_bits`。给定 `n` 时，所有 `ε` 的成本相同 |

全部五个字段均为必填。每个轴都是长度为 1…32 的数组，值在分数约分后唯一，输入数组的顺序保持不变。unit 数量等于各轴长度的乘积，且不超过 1 000 000。按 `N, n, a, D_budget` 的笛卡尔积从零编号，顺序与嵌套循环一致，预算变化最快。一个 unit 输出一个对象。

对于选定的点，令 `D=D_budget`，并将 `a=p/q` 约分。以每个位置一次前向遍历的 `1/q` 为单位度量计算量。于是考试需要 `E=n(q+Np)`，训练需要 `W=3Dq`，开销占比为 `E/W`。除以自身训练量源自 §5.4 中「附加费」的表述。20% 条件等价于 `5E ≤ W`。

| 结果字段 | 值 |
|---|---|
| `kernel` | 字符串 `t4-scale@1` |
| `N`, `n`, `D_budget` | 输入点的整数 |
| `a`, `epsilon` | 约分后的字符串 `p/q`；`epsilon` 写作 `1/q`，其中 `q = 2^epsilon_bits` 是十进制整数（例如 `epsilon_bits = 2` 时为 `"1/4"`） |
| `D_min` | 整数 `(5E + 3q − 1) // (3q)`，其中 `//` 是向下取整的整数除法。这是将阈值向上取整到整数个 token |
| `fits` | 布尔值 `D_budget ≥ D_min`。相等也计入 |
| `N_max` | 若 `W < 5nq` 且即使基线遍历也超出预算，则为 `null`。否则为整数 `(W − 5nq) // (5np)`。零表示只能容纳基线。上限可能超出输入轴 `N` |
| `overhead` | `E/W`，表示为约分后的字符串 `numerator/denominator` |

反向边界由 `p` 为正时的线性不等式 `5npN ≤ W − 5nq` 得出。在允许的参数下，`5E+3q−1 ≤ 5 000 005 000 002 999 999`，`W ≤ 3·10^18`。分母为正。有符号 64 位整数以及通过最大公约数约分分数就足够。在 Go 中，`overhead` 使用 `big.Rat`，`2^epsilon_bits` 使用 `big.Int`。每个 unit 最多解析 128 个轴元素，并进行常数次算术运算。

对于 `n=3, N=4, a=1/2`，考试花费 9 次遍历；在 15 个训练 token 时，它恰好占五分之一。在 14 个 token 时，上限降为三个提交者。当 `epsilon_bits=2` 时，得到以下规范字节。

```json
{"D_budget":15,"D_min":15,"N":4,"N_max":4,"a":"1/2","epsilon":"1/4","fits":true,"kernel":"t4-scale@1","n":3,"overhead":"1/5"}
```

作为 §5.4 的参考，当 `n=100000, N=10000, a=4/36` 时，精确最小值为 185 351 852 个 token。实际成本取决于前缀复用、缓存大小、输出头、归一化、流量以及上层训练的实际成本。该公式只涵盖 §5.4 所述的遍历计数。M10 用于评估 `ε` 变化时的统计阈值。提议的任务根据 D19 的数值参考设定 `ε=2^-80`。critic_gpt，关于 claude1 的一节，「T4 的隐藏成本」 · [ROADMAP, D18–D19](ROADMAP.md)

## M10. T4 的考试阈值 — `exam-thresholds@1`

M10 确定考试中观察到的平均改进必须多大，才能超过统计阈值。对于单个预先固定的候选，有放回地取 `n` 个独立位置。每个位置上的损失差被截断到 `[−B/2, B/2]`。输入 `V` 是截断差值的样本方差，除数为 `n−1`（标准差的平方）。以每位置 nat 计的边界取自 T4 描述的第 6 步。claude1，§5.4 · 评审者 Claude，§1.8

| 方法 | 精确阈值 `t` |
|---|---|
| Hoeffding | `B·√(ln(1/ε)/(2n))` |
| 经验 Bernstein | `√(2V·ln(2/ε)/n) + 7B·ln(2/ε)/(3(n−1))` |

**参数与 unit。** 五个字段均为必填。字段 `n`、`epsilon_bits`、`B`、`variance` 是长度为 1 到 32 的轴，各自按输入数组的顺序排列。轴上的值各不相同，分数在约分后比较。

| 字段 | 允许值 |
|---|---|
| `n` | 位置数量，从 2 到 1 000 000 的整数 |
| `epsilon_bits` | 从 1 到 128 的整数 `k`，每次比较 `ε = 2⁻ᵏ` |
| `B` | 截断范围的宽度，从 1 到 64 的整数 |
| `variance` | 分数 `[p,q]`，整数 `0 ≤ p ≤ 10⁶` 和 `1 ≤ q ≤ 10⁶`。在网格的所有点上，`V=p/q ≤ B²·floor(n/2)·ceil(n/2)/(n(n−1))` |
| `digits` | 一个从 1 到 9 的整数 `d`。每个区间的保证绝对宽度小于 `10⁻ᵈ` |

最大方差在范围端点处取得，因为方差对每个观测都是凸的。当有 `j` 个值位于一端时，其分子正比于 `j(n−j)`，这给出上述边界。unit 数量等于四个轴长度的乘积，且不超过 1 000 000。编号与 `itertools.product(n, epsilon_bits, B, variance)` 一致，从零开始。

**逐字节复现算法。** 对两种方法，写出 `t = √(A·ln 2) + C·ln 2`。对 Hoeffding，`A=B²k/(2n), C=0`。对 Bernstein，`A=2V(k+1)/n, C=7B(k+1)/(3(n−1))`。这里的所有除法都是有理数除法。

1. 取 `S=10^(d+1)`、`l=693147180559945309/10¹⁸`、`h=693147180559945310/10¹⁸`。
2. 下界等于 `(floor(√(S²Al)) + floor(SCl))/S`。上界等于 `(ceil(√(S²Ah)) + ceil(SCh))/S`。两个加项**分别**取整。
3. 对于非负分数 `x=p/q`，计算 `r=isqrt(p//q)`。这就是 `floor(√x)`。对于上界，当且仅当 `r²q < p` 时给 `r` 加一。普通的 `floor` 和 `ceil` 也通过整数除法实现。所有得到的分数都约分。

**精度证书。** 从 `2·atanh(1/3)=ln 2` 的级数中，取奇数 `j=1,3,…,39` 上的 `T=2·Σ 1/(j·3ʲ)`。余项为正，并以第一个被省略的项乘以 `1/(1−1/9)` 为上界。通过整数比较得到 `l < T < ln 2 ≤ T + 9/(4·41·3⁴¹) < h`。两个加项的单调性和定向舍入保证了真实阈值被包含在内。在给定范围内，`A ≤ 264192` 且 `C ≤ 19264`。由于 `√h+√l > 1`，将 `l` 替换为 `h` 使未取整的阈值变化小于 `(515+19264)·10⁻¹⁸`。取整使区间扩展小于 `4/S`。即使 `d=9`，总和也小于 `10⁻ᵈ`。每个 unit 只需四次整数平方根，以及对几百位大小的整数和分数进行常数次运算，与 `n` 无关。

**响应。** 字段 `n`、`epsilon_bits`、`B` 和 `digits` 是整数坐标和精度。`variance` 是约分后分数的字符串。`hoeffding` 和 `bernstein` 是由两个此类字符串组成的数组，下界在前。对于 `n=2, k=1, B=2, V=0, d=1`，内核输出以下规范字节。

```json
{"B":2,"bernstein":["323/50","647/100"],"digits":1,"epsilon_bits":1,"hoeffding":["83/100","21/25"],"kernel":"exam-thresholds@1","n":2,"variance":"0/1"}
```

对于给定的极限阈值 `τ`，当选定点的上界 `≤ τ`，且在相同参数下所有更小的 `n` 的下界都 `> τ` 时，**网格上**的最小考试规模即被确定。如果区间与目标相交，可能需要更高的精度。这些数字刻画的是在固定到外部信标之前对截断均值的单侧比较。在多个候选之间选择的校正、考试之外的质量、`τ` 的选择以及实际效应的大小，需要单独的数据或规则。根据 D18，为改进付费仍是研究性方案。[ROADMAP, D18–D20](ROADMAP.md) · 评审者 GPT，T4 评估

## M12. 按和合并时重复项所有者的计入额如何变化

M12 的指定作品给出了梯度和 Hessian 已知的线性二次损失、三种归因规则、精确重复和带噪声的重复。我们选择 §5.4 中明确分析的 `merge = sum` 变体。评审者给出了一个案例：即使重复添加同一步骤也会改善损失函数。内核 `merge-attribution@1` 在显式输入系数上检查这一点。claude1，§5.4 第 6–7 步和第 2 点「归因与重复」，§7.5 第 7 点 · critic_gpt，关于 claude1 的表格，T4 行

| `params` 字段 | 含义与包含端点的边界 |
|---|---|
| `scale` | 公共分母 `s`，整数 1…10 000 |
| `g` | 基点处梯度分子的向量。其长度给出维数 `d`，1…8 |
| `hessian` | Hessian 分子的对称矩阵，由 `d` 行、每行 `d` 个分量组成的数组 |
| `updates` | 由 `b=1…8` 个长度为 `d` 的原始分子向量组成的数组，按提交顺序排列。允许相同的向量 |
| `owner` | 被检查参与者原始申请的整数索引，从 0 到 `b−1`。其他原始申请属于其他参与者 |
| `copies` | 由 1…8 个不同的整数 1…8 组成的轴。选定的 `c` 给出同一参与者新增申请的数量 |
| `noise` | 由 1…32 个两两不同的长度为 `d` 的分子向量组成的轴。零向量给出精确重复 |
| `threshold` | 用于从每个申请评分中扣除 `t=threshold/s` 的整数分子 0…10 000 |

`g`、`hessian`、`updates` 和 `noise` 的每个分量都是 −10 000 到 10 000 的整数。要得到每个分量的数学值，将其除以 `s` **一次**，矩阵也是如此。该版本支持具有指定范围内公共分母的有理系数。对称性是必需的，曲率符号任意。输入轴 `copies, noise` 构成网格。对于 unit `u`，分别取索引 `divmod(u,len(noise))`。在原始 `b` 个申请之后添加 `c` 个向量，每个向量在分子上等于 `updates[owner] + noise[j]`。原始向量保留。添加前后的申请集合分别考虑。

**计算。** 令 `U` 为一个集合中申请的索引集合，`x(S)` 为子集 `S` 上其**数学**更新向量之和。损失收益定义为相对于共同基线的下降，

```text
v(S) = −gᵀx(S) − x(S)ᵀ H x(S)/2,     v(∅) = 0.
```

对于每个索引 `i`，计算三个**带符号**的评分。`separate[i]=v({i})`。留一（保留一个）规则，`loo[i]=v(U)−v(U без i)`。`shapley[i]` 评分等于在所有索引排列上 `v(S∪{i})−v(S)` 的平均增量，其中 `S` 由 `i` 的前驱组成。该规则应用于完整的损失下降函数。为在不进行阶乘枚举的情况下计算，令 `q_i=v({i})`、`h_ij=−x_iᵀ H x_j`。对称性给出对 `S` 中成员求和的 `v(S)=Σ q_i + Σ_{i<j} h_ij`。当排除一个成员时，其所有成对项消失。在均匀随机排列中，其他每个成员恰好在半数情况下位于它之前。因此

```text
loo[i]     = q_i + Σ_{j≠i} h_ij
shapley[i] = q_i + (Σ_{j≠i} h_ij)/2
v(U)       = Σ shapley[i].
```

接下来，对每种规则分别将评分 `z` 转换为以改进为单位的计入额 `max(0,z−t)`（支付系数 κ 取为一）。先按每个申请计入，然后相加所有者的计入额。`gain` 是添加后所有者为其原始申请及所有新增申请获得的计入额，减去添加前其单个申请的计入额。正号表示在此示例中额外提交带来收益。

**答案格式。** 键 `kernel`（字符串 `merge-attribution@1`）、`owner`、`scale`、`copies`（从轴中选出的整数）、`noise`（选出的整数分子向量）、`baseline`、`with_copies` 和 `gain`。`baseline` 和 `with_copies` 对象各包含 `value`——分数 `v(U)`——以及字段 `separate`、`loo`、`shapley`——按申请索引顺序排列的分数数组。`gain` 对象在三个规则名称下各包含一个分数。所有输出分数都是规范字符串。

**算术与界限。** 中间评分的公共分母是 `2s³`。如果 `G, A, z_i` 是梯度、Hessian 和步长的输入整数分子，则 `q_i` 的分子等于 `−2s Gᵀz_i−z_iᵀAz_i`。成对项的一半对应整数分子 `−z_iᵀAz_j`。扣除项的分子等于 `2s²·threshold`。添加后最多有 16 个申请，且 `|z_ij| ≤ 20 000`。由此 `|z_iᵀAz_j| ≤ 8²·20 000²·10 000 = 2,56·10¹⁴`，线性部分的模不超过 `3,2·10¹³`。即使 16 个完整 LOO 评分与扣除项之和的模也小于 `1,3·10¹⁷`。所有乘法和部分和都适合有符号 64 位。实现通过 `big.Rat` 约分分数。时间为 `O(k d²+k²d)`，其中 `k ≤ 16`，不使用子集表。内存受输入向量、矩阵、每个申请的三个评分和结果限制。

**手工校验。** 当 `v(x)=3x−x²/2`、单个申请 `x=1` 且阈值为零时，原始评分按所有规则都等于 `5/2`。精确重复后 `v(2)=4`。各规则分别对每个申请给出 `5/2`，留一给出 `3/2`，Shapley 给出 `2/1`。所有者的总收益相应为 `5/2`、`1/2`、`3/2`。仅此一个示例就足以在零阈值下，对这类模型的整个族反驳三种规则中每一种都不存在收益的论断。

**结论范围。** 比较参与者的集合是固定的。噪声由显式向量给出，阈值由输入给出。接受、扣除阈值后重新选择成员、提交成本、参数训练、外部效应和经验考试都在此模型之外。数值收益指的是按选定规则计算的计入额总和。D1 的完整检查还要求将联盟的效用与诚实工作和不作为进行比较。[THREAT_MODEL, §§1.4–1.5](THREAT_MODEL.md) · [ROADMAP, D18 和 D25](ROADMAP.md)

## M14. 用有限枚举校验公式

内核 `verification-enumerations@1` 复现三个小型实验。它可用于检查打包是否保持允许向量之间的区别，以及两种抽样检查各自漏过多少错误。初始数据、枚举顺序和参考哈希发布在 GPT2，§6.2 和「第一次复现的对照代码」中。链在「交给小型代理的内容」表中给出，域中的漏过条件在 §6.1 中。GPT2 作品 · [总结, §5.3](VERIFICATION_SEARCH.md)

唯一参数 `cases` 是由下表中 1–4 个不同字符串组成的数组。`units = len(cases)`。从零编号，unit `u` 计算整个实验 `cases[u]`。结果的 `case` 键包含同一字符串，`kernel` 等于 `"verification-enumerations@1"`。其余字段的格式取决于实验。

| `case` | 除 `case` 和 `kernel` 之外的结果字段 | 对照值 |
|---|---|---|
| `packing-8` | 整数 `total`、`true_accepts`、`false_accepts`，字符串 `verdict_sha256` | 441, 9, 0, `a5c8a8d715fb5293a4dd12753d3483e848f63cb24891a3e584bfdc81954f377c` |
| `packing-4` | 相同字段 | 441, 9, 20, `fca92fea5a3148177517b737591e499ed021432078bd9803578a2eaad4074fc9` |
| `chain-8-2` | 整数 `total`、`caught`、`missed` | 224, 56, 168 |
| `field-5` | 整数 `total`、`caught`、`missed` | 25, 20, 5 |

**位打包。** 从实验标签中取基数 `B`。按升序字典序枚举 `(x,y,c,d)`，其中 `x,y ∈ {−1,0,1}`，`c,d ∈ {−3,…,3}`。内层循环改变 `d`。真实结果为 `(s,t)=(2x−y,−x−y)`。接受判据是 `(c−s)+B(d−t)` 在整数上可被 `B²` 整除。当 `(c,d)=(s,t)` 时，接受会增加 `true_accepts`；其他接受情况则增加 `false_accepts`。按枚举顺序写入恰好 441 个字节，接受时每个字节值为 1，拒绝时为 0。`verdict_sha256` 是这些原始字节的 SHA-256，为 64 个小写十六进制数字。unit 的常规结果哈希独立于整个规范 JSON 计算。为手工校验，当 `B=4`、`x=−1`、`y=1` 时，真实答案 `(−3,0)` 和申报 `(1,−1)` 的差为 0。

**链。** 对于每个单一缺陷 `h=0,…,7`，按 `0 ≤ i < j < 8` 枚举所有无放回的无序对。每个三元组使 `total` 增加 1，如果 `h=i` 或 `h=j` 则使 `caught` 增加。漏过数量等于 `missed=total−caught`。对于每个 `h` 有 28 对，其中恰好 7 对包含 `h`。

**域。** 枚举向量 `(x,y)∈{0,…,4}²`，包括零向量。错误 `(1,−1)` 恰好当 `(x−y) mod 5 = 0` 时被漏过。`total` 统计所有向量，`missed` 统计漏过，`caught=total−missed`。五个对角对给出五次漏过。

最长的 unit 检查 441 种组合，为一个 SHA-256 保存 441 个判定字节。计数器不超过 441，打包表达式的模不超过 46，除法的最大模为 64。有符号 32 位整数就足够。结果适用于指定的范围、单个固定错误以及等概率变体的完整枚举。推广到真实协议需要论证调用的分布和检查的独立性。
