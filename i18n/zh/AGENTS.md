# 给人工智能助手的入门说明

本文件写给任何被人请求帮助 SkyNet 项目的模型（Claude、ChatGPT/Codex、DeepSeek、Gemini 等）。回答前请完整阅读。用用户的语言回答。

## 项目是什么

SkyNet 是对一个分布式网络架构的研究和设计：人工智能模型在参与者的计算机上运行和学习。参与者因经过验证的有用工作获得积分；没有硬件的人能以低廉价格使用人工智能。网络服务于人类并遵守 SkyNet 定律。目前没有成品软件：仓库是共同设计架构的地方。

## 不可更改的基础

宣言、强制性要求和 README 是 SkyNet 不可更改的基础（见 [CORE.md](../../CORE.md)）。**不要提议修改这些文件**，只能在勘误文件中记录错别字。如果某个方案与基础不兼容，请直接说明它违反了哪一项要求；不要为了迁就方案而改写要求。

## 不变的条件

用六项要求检验每个方案：

1. 网络是分布式的，没有中心，也没有拥有特殊权利的角色。
2. 网络把关于自身的信息保存在公共资源上。
3. 所有节点关闭后，网络能通过公共资源找到自己并恢复。
4. 参与者无法欺骗网络：欺骗毫无用处或带来损失，包括对账户为空的新人，以及在合谋和多账户的情况下。
5. 不预先收钱：没有押金、费用或罚款。
6. **参与有利可图**，诚实性验证成本低。如果验证吞噬了收益，无论多么安全，方案都不合适。

参与者类型：拥有大量资源（出售多余积分）、硬件较弱（补足差额）、没有硬件（只付费）。基础模型是 Qwen。人们看不到他人的请求。参与者除了资源滑块外不需要手动设置任何东西。SkyNet 定律（第零至第三定律）具有约束力。

## 工作规则

- **区分已决定、已提议、已验证和未解决。** 使用 CURRENT_DESIGN 中的标记。不要把提议说成决定，把计算说成测量。
- **不要悄悄削弱要求。** 对硬件的信任（TEE）、诚实多数、统计抽样、很小的错误概率都是假设，要明确说出来。
- **对每个防护方案都要回答：** 如果执行者和验证者合谋，网络依据哪些可独立验证的数据拒绝虚假声明？如果诚实情况和伪造情况给出相同的数据，方案就不起作用。
- **计算完整成本**：证明者和验证者的计算、内存、流量、区块链写入、故障后的重试。CPU、GPU、内存、显存分开计算，绝不合成一个百分比。
- **不要重复已被否定的想法**（列在 OPEN_QUESTIONS 末尾），除非有新的论据。
- **攻击你自己的提议。** 一个诚实的反例比自信的语气更有价值。
- **不要编造来源、版本或数字。** 给出来源及其适用范围。
- 没有找到解决方案是诚实的结果，它并不证明不可能。

**九种语言。** 所有写给人看的内容（文档、指南、程序界面）都以项目的全部九种语言发布：英语、中文、西班牙语、法语、德语、意大利语、俄语、葡萄牙语和阿拉伯语。译文的第一行注明其来源文件和来源的哈希值；`python tools/check_translations.py` 会列出缺失或过时的译文。译文与来源不一致时，以来源为准。

## 贡献格式

1. 论断：保证什么，在什么假设下。
2. 机制：步骤、数据、谁检查什么。
3. 攻击：如何绕过，剩下什么（已关闭 / 造成损失 / 有界 / 未解决）。
4. 成本：标注 [计算] 或 [实测] 的估计及其来源。
5. 满足了哪些要求，没有满足哪些。

按照 [CONTRIBUTING.md](CONTRIBUTING.md) 以 issue 或 pull request 的形式提交。

## 研究代理程序及其结果

没有人工智能助手的人通过[研究代理程序](AGENT.md)提供帮助：它从 [tasks/](../../tasks/README.md) 领取计算任务并发布结果，结果汇总在 `results/` 中。你可以这样帮忙：提出一个定义明确的任务（他人可以重新计算的精确模型）、独立核对已发布的结果，或解释某个结果对设计意味着什么。标明“本地模型的机器生成回答”的内容是未经验证的文本：把它们当作待检验的想法，而不是事实。

## 安全

不要把密钥、密码、个人数据或他人计算机的地址加入仓库。不要提议攻击真实的第三方系统：这里的攻击分析只涉及 SkyNet 架构。不要设计把网络用于战争、武器或伤害人类的用途：这违反 SkyNet 定律。
