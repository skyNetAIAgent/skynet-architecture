# Установщик для Windows x64

[English](../../installer/windows/README.md) · [中文](../zh/WINDOWS_INSTALLER.md) · [Español](../es/WINDOWS_INSTALLER.md) · [Français](../fr/WINDOWS_INSTALLER.md) · [Deutsch](../de/WINDOWS_INSTALLER.md) · [Italiano](../it/WINDOWS_INSTALLER.md) · **Русский** · [Português](../pt/WINDOWS_INSTALLER.md) · [العربية](../ar/WINDOWS_INSTALLER.md)

Скачайте EXE-файл и подходящий файл `.exe.sha256` из одного и того же выпуска проекта. В
PowerShell откройте папку загрузок и сравните контрольную сумму. [Выпуски GitHub](https://github.com/skyNetAIAgent/skynet-architecture/releases)

```powershell
$file = 'SkyNetAgentSetup-0.2.2.exe'
$expected = ((Get-Content -Raw "$file.sha256") -split '\s+')[0]
if ((Get-FileHash $file -Algorithm SHA256).Hash -ne $expected) { throw 'Checksum mismatch.' }
```

Откройте проверенный EXE-файл. SmartScreen может показать **Windows защитила ваш компьютер**,
потому что у установщика нет подписи кода. Выберите **Подробнее**, убедитесь в имени файла,
затем выберите **Выполнить в любом случае**. Установка выполняется для текущего пользователя.
Снимите любой из флажков автозапуска, чтобы изменить, когда запускается агент.

Агент принимает подписанные обновления своих собственных файлов. Более новый установщик
обновляет встроенный Python. Установите поверх существующей копии, чтобы сохранить
идентичность устройства и ожидающие результаты. Программа удаления в меню «Пуск» по умолчанию
тоже их сохраняет. Его необязательный флажок удаления данных включает «исходящие» и
ожидающие подписанные записи.

## Сборка и тестирование

Используйте чистую копию репозитория с переводами строк LF для подписанных файлов. Из корня
репозитория в Windows x64 запустите PowerShell 7 с новой папкой сборки. Сборка проверяет
наличие Inno Setup 6.3.3 или новее в PATH или в обычном месте установки. Если компилятора
нет, она устанавливает 6.3.3 через Chocolatey.

```powershell
./installer/windows/build.ps1 -BuildDir build
```

`python.lock` должен содержать точную версию 3.12 (включая номер патча) и 64-значный
SHA-256 официального архива `python-<version>-embed-amd64.zip`. Для новой фиксации версии
проверьте подлинность архива по инструкции и пакету Sigstore, ссылки на которые есть на
странице выпуска Python, затем запишите его SHA-256. Пустое или неверное значение фиксации
останавливает сборку до загрузки. [Выпуск Python 3.12.10](https://www.python.org/downloads/release/python-31210/)

Сборка проверяет архив перед распаковкой. Встроенный интерпретатор готовит к установке только
файлы из проверенного манифеста выпуска. Во время установки он снова проверяет пакет,
включая список его файлов, прежде чем запустить пробную версию. Штатный файл `python312._pth`
подключает стандартную библиотеку. Запускатель и проверка пробной версии добавляют папку
выбранного выпуска в `sys.path` при работе с `-I`.

В одноразовом профиле Windows, где SkyNet ещё не установлен, запустите дымовой тест. Он
устанавливает агент без запросов, проверяет регистрацию при входе в систему и CLI без
системного Python в PATH, затем удаляет агент и проверяет сохранённые данные.

```powershell
./installer/windows/smoke.ps1 -BuildDir build
```

Или запустите **Actions → Windows installer → Run workflow**. После успешного дымового теста
скачайте артефакт `SkyNetAgentSetup-x64`. Его `SkyNetAgentSetup-<version>.exe` и
`.exe.sha256` — это два файла, которые нужно вручную прикрепить к соответствующему выпуску
GitHub.
