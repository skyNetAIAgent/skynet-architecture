# Как участвовать

[English](../../CONTRIBUTING.md) · [中文](../zh/CONTRIBUTING.md) · [Español](../es/CONTRIBUTING.md) · [Français](../fr/CONTRIBUTING.md) · [Deutsch](../de/CONTRIBUTING.md) · [Italiano](../it/CONTRIBUTING.md) · **Русский** · [Português](../pt/CONTRIBUTING.md) · [العربية](../ar/CONTRIBUTING.md)

Спасибо, что хотите помочь. Здесь важны не объём текста, а точность: одна найденная дыра
с конкретным сценарием ценнее десяти страниц общих рассуждений.

## Что приносить

- **Атаку на текущий проект.** Сценарий: кто действует, что делает, что получает, почему сеть
  этого не замечает. Укажите раздел [CURRENT_DESIGN](../../docs/CURRENT_DESIGN.md).
- **Решение открытого вопроса** из [OPEN_QUESTIONS](../../docs/OPEN_QUESTIONS.md).
- **Источник**: статью, протокол, проект, которые закрывают часть задачи, с версией, датой
  и тем, что в нём **не** доказано для нашего случая.
- **Расчёт стоимости** или поправку к существующему.
- **Перевод**: исправление неточности в переводе основы (через файл исправлений).
- **Задание для программы-агента**: расчёт, который отвечает на часть открытого вопроса
  (см. [tasks/README.md](../../tasks/README.md)).
- **Вычислительную мощность**: если нет ИИ-ассистента и времени писать, запустите
  [программу-агент](AGENT.md) на компьютере или телефоне.

## Как оформлять

Откройте issue и начните заголовок с метки:

| Метка | Для чего |
|---|---|
| `[Attack]` | Найден способ обмана или отказа |
| `[Q<N>]` | Предложение по открытому вопросу N |
| `[Source]` | Полезная работа или проект |
| `[Cost]` | Оценка стоимости, поправка к числам |
| `[Translation]` | Неточность перевода |
| `[Task]` | Расчёт для программы-агента |

В тексте укажите:

1. Что гарантируется и при каких допущениях.
2. Механизм.
3. Известные атаки и что остаётся.
4. Цену с пометкой [расчёт] или [измерено].
5. Какие из шести [требований](REQUIREMENTS.md) выполнены, а какие нет.

Pull request с правками рабочих документов (`docs/`) приветствуется. Меняя статус пункта,
объясните почему.

## Правила

- **Основа не меняется.** Pull request, который меняет манифест, требования или README
  в `i18n/ru/` и их отпечатки, не принимается. См. [CORE.md](../../CORE.md).
- Расчёт не выдаётся за измерение, предложение — за принятое решение.
- Не публикуйте ключи, пароли, личные данные, адреса компьютеров.
- Вежливость и предметность. Критикуйте идеи, а не людей.

Если работаете с ИИ-ассистентом, дайте ему [AGENTS.md](AGENTS.md). За точность текста
отвечает автор issue.
