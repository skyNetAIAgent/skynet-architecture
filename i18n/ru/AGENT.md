# Исследовательский агент SkyNet

[English](../../agent/README.md) · [中文](../zh/AGENT.md) · [Español](../es/AGENT.md) · [Français](../fr/AGENT.md) · [Deutsch](../de/AGENT.md) · [Italiano](../it/AGENT.md) · **Русский** · [Português](../pt/AGENT.md) · [العربية](../ar/AGENT.md)

Вы можете помочь проектировать SkyNet, позволив своему компьютеру выполнить часть исследования. Агент — небольшая программа с открытым исходным текстом. Он проверяет этот репозиторий на наличие заданий, выполняет часть расчёта и делится результатом. Вы также можете разместить исследовательский вопрос или ответить на чужой на доске задач. Учётная запись и ИИ-ассистент не нужны. [Руководство по доске задач](../../docs/BOARD.md)

**На этом этапе вознаграждений не предусмотрено.** Ни кредитов, ни платежей, ни обещаний будущих выплат. Это добровольное исследование, помогающее проектировать сеть SkyNet.

## Что она делает и чего не делает никогда

| Делает | Не делает никогда |
|---|---|
| Читает подписанный список заданий. Каждое задание называет встроенный расчёт и передаёт его входные данные | Запускает код из задания или сообщения на доске |
| По умолчанию выполняет одну порцию работы за раз с низким приоритетом процессора | По умолчанию начинает новую порцию при обнаружении питания от батареи |
| Подписывает результаты ключом этого устройства и по умолчанию отправляет их на публичные ретрансляторы и полный узел | Включает ваши личные файлы или идентификаторы оборудования в автоматический результат |
| Проверяет подпись проекта перед установкой обновления для настольных систем | Принимает скачанное обновление с неверной подписью, неверным хешем файла или меньшим номером выпуска |
| Устанавливается в профиль пользователя и позволяет выбрать, запускаться ли при входе в систему | Требует прав администратора для обычной установки на настольную систему |

Один из исследовательских вопросов — может ли участник, который собирается уйти, получить выгоду от всплеска поддельных результатов. Сколько проверяющих должны ему помочь? Разные устройства, получившие одну и ту же часть этого расчёта, должны получить в точности один и тот же ответ, поэтому их результаты можно сравнить. [Исследовательские задания](../../tasks/README.md)

## Что нужно

- Windows на x64 (amd64) или ARM64 либо Linux на amd64, arm64 или ARMv7. Настольный агент в 1.0.1 — одна программа на Go. Установщики со страницы Releases включают исполняемый файл, готовый к запуску. macOS не поддерживается.
- Для опытного приложения для Android — Android 7.0 или новее на arm64-v8a или x86_64.
- Подключение к интернету для получения новых заданий и публикации результатов. Установщик для Linux со страницы Releases умеет устанавливать без интернета.

## Установка

**Windows**

1. Выберите установщик для Windows (`.exe`) для своего компьютера, amd64 или arm64, со страницы [Releases](https://github.com/skyNetAIAgent/skynet-architecture/releases).
2. Сравните контрольную сумму SHA-256 файла с контрольной суммой из источника, которому доверяете, затем запустите установщик. Можно выбрать запуск агента сейчас и запуск при входе в систему. Программа установки добавляет ярлыки в меню «Пуск». [Руководство по установщику для Windows](../../installer/windows/README.md)

**Linux**

Скачайте `skynet-agent-install.sh` со страницы [Releases](https://github.com/skyNetAIAgent/skynet-architecture/releases) и выполните `sh skynet-agent-install.sh` от имени своего обычного пользователя. Файл включает исполняемые файлы для всех трёх поддерживаемых архитектур Linux.

Можно также установить по сети командой ниже. Для неё нужны `curl`, `jq`, `xxd`, `sha256sum` и OpenSSL с поддержкой Ed25519.

```sh
curl -fsSL https://raw.githubusercontent.com/skyNetAIAgent/skynet-architecture/main/agent/install.sh | sh
```

По умолчанию программа установки сохраняет текущую настройку запуска при входе. При первой установке запустите агент сами командой `skynet-agent run`. Чтобы запустить его сейчас и при входе в систему, выполните `sh skynet-agent-install.sh --autostart`. Для этого используется ваша пользовательская служба systemd. Добавьте `--linger`, чтобы работать с момента загрузки и после выхода из системы, или `--no-autostart`, чтобы выключить службу. Если оболочка не находит команду, используйте `~/.local/bin/skynet-agent`. [Руководство по установщику для Linux](../../installer/linux/README.md)

**Android (опытная версия)**

Скачайте `skynet-agent.apk` со страницы [Releases](https://github.com/skyNetAIAgent/skynet-architecture/releases). Откройте файл и разрешите установку из браузера или файлового менеджера, когда Android спросит. Откройте **SkyNet Agent** и нажмите **Start**. По умолчанию приложение считает только во время зарядки. **Start after reboot** по умолчанию выключено.

У APK собственный номер версии. Версия приложения 0.3.0 включает агент на Go версии 1.0.0. Приложение предлагает обновления на своём экране или в уведомлении. Перед тем как попросить вас подтвердить установку в Android, оно проверяет подписанное описание выпуска, размер APK и его SHA-256. [Руководство по Android](../../android/README.md)

Ключ устройства, настройки и результаты хранятся в папке агента. По умолчанию это `%LOCALAPPDATA%\SkyNetAgent` в Windows и `~/.local/share/skynet-agent` в Linux (или `$XDG_DATA_HOME/skynet-agent`, если эта переменная задана). Установщик для Linux также принимает `SKYNET_AGENT_HOME` или `--home DIR`, чтобы выбрать другую папку. Android хранит свой профиль в закрытом хранилище приложения.

Если вы уже запускаете агент на Python на поддерживаемой настольной системе с включёнными автоматическими обновлениями, он сам перейдёт на Go через подписанный промежуточный выпуск **0.4.0**. Ключ устройства, прогресс и неотправленные результаты сохранятся. Предыдущий промежуточный выпуск и его интерпретатор сохраняются для отката.

## Первые шаги

В Linux используйте команды ниже. В Windows откройте PowerShell в папке агента и используйте `.\skynet-agent.exe launch` вместо `skynet-agent`. Например, `.\skynet-agent.exe launch status` показывает состояние через постоянный запускатель.

```sh
skynet-agent verify-install       # проверить установленные файлы выпуска и выполнить тестовый расчёт
skynet-agent selftest --online    # выполнить расчёт и проверить подписанные документы по сети
skynet-agent net id               # открытый ключ этого устройства, его имя на доске
skynet-agent run                  # если ещё не запущен, работать, пока не нажмёте Ctrl+C
```

Команда `skynet-agent autostart status` показывает, включён ли запуск при входе в систему. Чтобы включить его, используйте `skynet-agent autostart enable`.

### Публикация результатов

Агент сохраняет каждый готовый результат в «исходящие». Он использует ключ подписи из файла `identity.key` в папке агента и создаёт его при первом использовании, если файла нет. По умолчанию он отправляет подписанный результат на публичные ретрансляторы Nostr и полный узел. Прежде чем агент переведёт результат в `sent`, получение должны подтвердить один узел или два разных ретранслятора. Иначе результат остаётся в «исходящих». Каждая повторная попытка использует ту же подписанную запись с тем же ID.

Вот часть результата для задания, использующего встроенный тестовый расчёт. Полный результат также содержит имя задания, время выполнения в секундах, версию формата, номер выпуска агента и, по умолчанию, метку платформы. Подписанная запись вокруг него содержит открытый ключ устройства, отметку времени, ID записи и подпись.

```json
{
  "agent": "1.0.1", "kernel": "selftest@1", "unit": 0, "units": 1,
  "result": {
    "kernel": "selftest@1", "rounds": 8, "ok": true,
    "digest": "a2e8f2c45179bfccb6a01d61ab527a86277215a6ee85ff824910fe27d3e9fe26"
  },
  "result_sha256": "7823a03918e86a7046e437fdf001dc40ff05fb1d241a8917baeae4d88b5629fa"
}
```

## Команды

| Настольная команда | Что делает |
|---|---|
| `skynet-agent run` | Работает до остановки. `--once` выполняет не более одной порции. `--no-submit` оставляет результаты локально на время этого запуска. `--no-update` пропускает установку обновлений. `--verbose` добавляет подробности в журнал. |
| `skynet-agent status` | Показывает версию, папку агента, состояние питания, счётчики работы, ожидающие результаты и недавние проблемы. |
| `skynet-agent tasks` | Перечисляет автоматические исследовательские задания, какие готовы и сколько порций выполнило это устройство. |
| `skynet-agent pause` / `resume` | Даёт активным порциям завершиться и перестаёт начинать новые либо снова разрешает новые порции. |
| `skynet-agent stop` | Просит работающий агент завершиться. |
| `skynet-agent outbox` | `list` показывает ожидающие результаты, `show NAME` показывает один, `send` пытается опубликовать подходящие результаты, а `drop NAME` удаляет результат из очереди. |
| `skynet-agent net` | Просматривайте доску с помощью `tasks` или `show`. Для участия используйте `post-task`, `claim`, `report`, `accept` или `revise`. `sync` повторяет отправку ожидающих публикаций на доске и получает записи. `id` показывает ваш открытый ключ. [Руководство по доске](../../docs/BOARD.md) |
| `skynet-agent config` | `show` перечисляет настройки, `get KEY` показывает одну, а `set KEY VALUE` изменяет её. |
| `skynet-agent update` | Проверяет наличие более нового подписанного выпуска для настольных систем и устанавливает его, если он подходит этому устройству. |
| `skynet-agent selftest [--online]` | Проверяет расчёт по известному ответу. Добавьте `--online`, чтобы проверить подписи в списке заданий и в описании более старого выпуска проекта. |
| `skynet-agent verify-install` | Проверяет установленные файлы выпуска и выполняет тестовый расчёт. |
| `skynet-agent version` | Показывает версию агента, номер выпуска, версию Go и платформу. |
| `skynet-agent autostart` | `status` показывает, включён ли запуск при входе в систему. `enable` включает его, а `disable` выключает. |
| `skynet-agent uninstall --yes` | Удаляет установку в Linux. Добавьте `--purge`, чтобы удалить и сохранённые данные. |

## Настройки

| Настройка | По умолчанию | Смысл |
|---|---|---|
| `workers` | 1 | Сколько порций настольный агент может выполнять одновременно, от 1 до 256. Android выполняет одну. |
| `run_on_battery` | false | Разрешить вычисления при питании от батареи. |
| `paused` | false | Ждать, прежде чем начинать новые порции. Команды `pause` и `resume` изменяют эту настройку. |
| `poll_minutes` | 30 | Приблизительный интервал между проверками репозитория, от 5 до 1440 минут. У неудачных проверок свой график повторных попыток. |
| `update` | auto | На настольных системах `auto` устанавливает подходящие подписанные обновления, `notify` записывает в журнал, когда обновление доступно, а `off` пропускает установку и уведомления. Все три режима по-прежнему проверяют подписанную паузу от ведущих. |
| `submit` | auto | `auto` отправляет результаты по мере выполнения работы. `manual` держит их в «исходящих», пока вы не выполните `skynet-agent outbox send`. |
| `submit_via` | net | Публиковать подписанные записи через ретрансляторы и узлы. Это единственный работающий канал в 1.0. |
| `max_task_minutes` | 120 | Ограничение времени на порцию, от 1 до 1440 минут. Более короткий предел, указанный в задании, имеет приоритет. |
| `report_platform` | true | Включать операционную систему, архитектуру процессора и версию Go в новые результаты, например `linux-amd64-`, за которым следует версия Go. |

Например, `skynet-agent config set workers 4` разрешает до четырёх настольных обработчиков. Для совместимости со старыми установками `skynet-agent config show` также перечисляет прежние ограничения на комментарии и настройки ИИ. Они не влияют на вычисления на Go и публикацию в сети.

## По желанию: отвечать на исследовательские вопросы своей локальной ИИ-моделью

Режим локальной ИИ недоступен в 1.0. Вы по-прежнему можете написать и опубликовать свой ответ на доске задач.

## Безопасность, честно

- **Обновления и списки заданий подписаны.** Агент проверяет их подписи Ed25519 по ключу выпуска проекта, встроенному в программу. Перед переходом на обновление для настольных систем он проверяет номер выпуска, размер и SHA-256 исполняемого файла и выполняет тестовый расчёт. Он отвергает более старые списки заданий и перестаёт начинать работу из просроченного списка.
- **Задания передают данные.** Единственные расчёты, которые может выбрать задание, встроены в исполняемый файл. Чтобы добавить новый вид расчёта, нужен новый выпуск для настольных систем или обновление приложения для Android. [Исходный текст расчётов на Go](https://github.com/skyNetAIAgent/skynet-architecture/tree/main/agent-go/kernels)
- **Каждая порция выполняется в отдельном процессе** под вашей учётной записью. Обработчик запрашивает низкий приоритет процессора. Агент останавливает обработчик, если тот достигает предела времени.
- **Обновление для настольных систем может откатиться.** Запускатель проверяет активный выпуск перед его запуском. Если проверка не проходит или три попытки запустить агента подряд аварийно завершаются в течение первой минуты, запускатель может восстановить проверенный предыдущий выпуск, если он доступен. Он запоминает номер неудачного выпуска.
- **Ключ вашего устройства — незашифрованный файл.** Любой, кто скопирует `identity.key`, сможет подписывать от имени этого устройства. Личная резервная копия позволяет сохранить своё имя на доске после переустановки.
- **Первая установка зависит от того, где вы берёте установщик или скрипт.** После установки тот, кто контролирует ключ выпуска проекта, может подписывать новый код, который выполняется с вашими правами пользователя. На этом исследовательском этапе ключ находится у ведущих. Чтобы сначала просматривать обновления для настольных систем, выполните `skynet-agent config set update notify` и запускайте `skynet-agent update`, когда будете готовы. Предполагаемая сеть SkyNet должна работать без центрального ключа выпуска. [Устройство исследовательского агента и таблица угроз, на русском](../../docs/RESEARCH_AGENT.md)

## Приватность

GitHub видит ваш IP-адрес, когда вы скачиваете задания или обновления. Ретрансляторы и полные узлы, к которым вы обращаетесь, также видят ваш IP-адрес. Встроенный полный узел использует незашифрованный HTTP. Результаты и сообщения на доске публичны. По их открытому ключу читатели могут связывать записи с одного устройства.

Автоматические результаты содержат данные расчёта и поля, описанные выше. Используйте `skynet-agent config set report_platform false`, чтобы не включать метку платформы в будущие результаты. Агент не сканирует ваши личные файлы и не включает серийные номера оборудования. Когда вы публикуете задание или отчёт на доске, выбранный вами для отправки текст становится публичным.

## Чего это стоит вам

Занятый обработчик может использовать примерно одно ядро процессора. Низкий приоритет помогает другим программам получать процессорное время, когда оно им нужно. Работа всё равно расходует электроэнергию и может выделять тепло. На ноутбуке агент проверяет питание примерно раз в минуту. По умолчанию при обнаружении питания от батареи он ждёт и не начинает новые порции. Уже выполняющаяся порция может завершиться, а настольный агент может начать работу, если источник питания неизвестен.

В Android отключение от зарядки отменяет текущую порцию и оставляет её доступной для повторной попытки. Выберите в приложении **Also work on battery power**, если хотите, чтобы оно продолжало считать без зарядки.

## Удаление

В Windows используйте программу удаления **SkyNet Agent**. По умолчанию она сохраняет ключ устройства, очереди и историю выпусков. Чтобы удалить и их, выберите при удалении вариант удаления данных.

В Linux выполните следующую команду. Она выключает пользовательскую службу, останавливает агент и удаляет установленные программы. Ключ, настройки, прогресс и очереди сохраняются.

```sh
skynet-agent uninstall --yes
```

Чтобы удалить и сохранённые данные агента, при удалении выполните `skynet-agent uninstall --yes --purge`. В Android удалите **SkyNet Agent** через настройки Android, чтобы удалить приложение и его локальные данные. Опубликованные записи остаются публичными.

## Если что-то не так

- **«no valid signature from a trusted key»** означает, что скачанный документ не прошёл проверку. Агент его отвергает. Он по-прежнему может использовать ранее проверенный список заданий, пока этот список не истечёт. На настольных системах `skynet-agent status` показывает последнюю ошибку репозитория. Журнал работы — `logs/agent.log` в папке агента.
- **Результаты остаются в «исходящих».** Используйте `skynet-agent status` или `skynet-agent outbox list`, чтобы увидеть, что ожидает. В ручном режиме выполните `skynet-agent outbox send`. Если отвечает слишком мало ретрансляторов или узлов, результат остаётся в очереди для следующей попытки.
- **В старой установке появляется «GitHub submission is unsupported».** Выполните `skynet-agent config set submit_via net`, чтобы использовать подписанные записи для новых результатов. Записи, уже помеченные для GitHub, и старые ответы ИИ остаются в «исходящих» для просмотра.
- **Агент работает, но новая работа не начинается.** Проверьте `skynet-agent tasks` и журнал работы. Возможно, агент на паузе, ждёт питания, у него закончились подходящие задания или он ждёт места в «исходящих». В Android подключите зарядное устройство и нажмите **Start**, если вы ранее останавливали приложение.

## Что проверено

Тесты агента автоматически выполняются в Windows и Linux. Они охватывают подписанные списки заданий, расчёты с известными ответами, обновления и откат, подписанные записи, доставку, доску задач и прогон, который запускает обработчик и доставляет его результат на имитированный узел.

Установки проверялись вживую на Windows 11, Linux Mint, Ubuntu Server и эмуляторе Android 14. Приложение для Android ещё не проверено на физическом устройстве. Если что-то не работает в вашей системе, откройте, пожалуйста, задачу.
