# Программа-агент SkyNet

[English](../../agent/README.md) · [中文](../zh/AGENT.md) · [Español](../es/AGENT.md) · [Français](../fr/AGENT.md) · [Deutsch](../de/AGENT.md) · [Italiano](../it/AGENT.md) · **Русский** · [Português](../pt/AGENT.md) · [العربية](../ar/AGENT.md)

Чтобы помогать проектировать SkyNet, ИИ-ассистент не обязателен. Программа-агент — небольшая
программа с открытым исходным текстом. Она периодически заглядывает в этот репозиторий, берёт
исследовательские задания, считает их на вашем компьютере в свободное время и публикует результаты.
Она также даёт вам [доску задач](../../docs/BOARD.md), где люди и их ИИ-ассистенты размещают
исследовательские задания и отвечают на них. Учётная запись нигде не нужна.

**На этом этапе вознаграждений нет**: ни кредитов, ни денег, ни обещаний будущих выплат.
Это добровольная помощь исследованию. Агент — не сеть SkyNet, а инструмент для её проектирования.

## Что она делает и чего не делает никогда

| Делает | Не делает никогда |
|---|---|
| Читает из репозитория подписанный список заданий и подписанное описание версии | Не запускает код из задания. Задание — это имя встроенного расчёта и числа |
| Считает встроенные расчёты с низшим приоритетом, по умолчанию по одному | Не работает от батареи, пока вы этого не разрешите |
| Публикует каждый результат как запись, подписанную собственным ключом этого устройства, через публичные ретрансляторы и полные узлы | Не отправляет ваши файлы, идентификаторы оборудования и что-либо ещё с компьютера |
| Обновляется сама, но только на версию, подписанную ключом выпуска проекта | Не ставит обновление с неверной подписью, неверным отпечатком файла или меньшим номером |
| Устанавливается в профиль пользователя и позволяет выбрать, запускаться ли при входе в систему | Не требует прав администратора |

Первые задания — точные расчёты по правилам оплаты SkyNet, например: «может ли участник,
который уходит из сети, заработать на пачке поддельных результатов, и при какой доле
сговорившихся проверяющих». На любом устройстве должны получиться одни и те же цифры,
а результаты разных людей сверяются. Подробнее: [tasks/README.md](../../tasks/README.md).

## Что нужно

- Установщик для Windows x64 включает Python. Другие способы требуют Python 3.9 или новее.
- Несколько мегабайт на диске и доступ в интернет.

## Установка

**Windows x64**

1. Скачайте `SkyNetAgentSetup-<version>.exe` со страницы [Releases](https://github.com/skyNetAIAgent/skynet-architecture/releases) и запустите его. Установщик предлагает запустить агент сейчас и при входе в систему Windows. Оба флажка отмечены по умолчанию. Инструкции по проверке контрольной суммы и по SmartScreen см. в [руководстве по установщику для Windows](../../installer/windows/README.md).
2. Если Python уже установлен, можно установить из PowerShell.

```powershell
irm https://raw.githubusercontent.com/skyNetAIAgent/skynet-architecture/main/agent/install.ps1 | iex
```

**Linux и macOS** (терминал):

```sh
curl -fsSL https://raw.githubusercontent.com/skyNetAIAgent/skynet-architecture/main/agent/install.sh | sh
```

**Android, приложение (опытное)**: скачайте `skynet-agent.apk` со страницы [Releases](https://github.com/skyNetAIAgent/skynet-architecture/releases), разрешите браузеру установку приложений и откройте файл. Приложение работает только пока устройство заряжается; результаты публикуются как подписанные записи, учётная запись не нужна. На настоящем устройстве ещё не проверено. Исходный код и подробности: [android/README.md](../../android/README.md).

**Android**: установите приложение [Termux](https://termux.dev) из F-Droid, откройте его и выполните:

```sh
pkg install python curl
curl -fsSL https://raw.githubusercontent.com/skyNetAIAgent/skynet-architecture/main/agent/install.sh | sh
```

На телефоне агент работает, только пока телефон заряжается. Если он не может определить,
заряжается ли телефон, он ждёт и сообщает об этом; тогда установите приложение Termux:API
и выполните `pkg install termux-api` или разрешите работу от батареи:
`skynet-agent config set run_on_battery true`.

Если хотите сначала прочитать, что запускаете: скачайте
[`install.py`](../../agent/install.py), прочитайте его (он короткий) и выполните `python3 -I install.py`.

Установщик кладёт агент в одну папку (`%LOCALAPPDATA%\SkyNetAgent` в Windows,
`~/Library/Application Support/SkyNetAgent` в macOS, `~/.local/share/skynet-agent` в Linux
и Android) и создаёт команду `skynet-agent`. При установке из командной строки запустите агент сами.

## Первые шаги

```sh
skynet-agent selftest --online    # проверить устройство и подписи
skynet-agent net id               # открытый ключ этого устройства: его имя в сети
skynet-agent run                  # работать, пока не нажмёте Ctrl+C
skynet-agent autostart enable     # по желанию: запускаться при входе в систему
```

В Windows запускайте `.\skynet-agent.cmd` из папки агента. EXE-установщик добавляет в меню «Пуск» в раздел **SkyNet Agent** ярлыки для просмотра состояния, паузы, возобновления и остановки. Агент обновляет свои файлы из подписанных версий. Чтобы обновить встроенный Python, запустите более новый установщик.

### Публикация результатов

Когда агент запускается, он создаёт ключ для этого устройства (файл `identity.key` в папке
агента). Каждый результат — это небольшая запись, подписанная этим ключом. Агент сразу
отправляет её на несколько публичных ретрансляторов Nostr разных владельцев и на полные узлы,
перечисленные в агенте; результат считается доставленным, когда его подтвердили два
ретранслятора или один узел. Иначе она остаётся в «исходящих» и отправляется позже снова,
той же самой записью, поэтому она никогда не учитывается дважды.

Записи публичны и содержат открытый ключ этого устройства, поэтому результаты одного
устройства можно связать между собой. Если вы предпочитаете прежний способ — комментарии
в задаче GitHub под вашей учётной записью — выполните `skynet-agent config set submit_via github`
и войдите через [GitHub CLI](https://cli.github.com) (`gh auth login`), затем проверьте командой
`skynet-agent github`.

Опубликованный результат выглядит так и не содержит ничего другого:

```json
{"agent":"0.2.0","elapsed_s":41.2,"kernel":"exit-scam-a@1","platform":"linux-amd64-py3.12",
 "result":{"count":364838,"digest":"…","hits":0,"…":"…"},"result_sha256":"…","seq":1,
 "task":"exit-a-honest-check","unit":17,"units":256,"v":1}
```

## Команды

| Команда | Что делает |
|---|---|
| `skynet-agent run` | Работает до остановки. `--once` выполняет одну порцию и выходит |
| `skynet-agent status` | Версия, настройки, счётчики, ожидающие результаты, последняя неполадка |
| `skynet-agent tasks` | Опубликованные задания и что уже сделано на этом устройстве |
| `skynet-agent pause` / `resume` | Не брать новые задания / брать снова |
| `skynet-agent stop` | Попросить работающий агент завершиться |
| `skynet-agent outbox` | Результаты, ожидающие публикации (`list`, `show`, `send`, `link`, `approve`, `drop`) |
| `skynet-agent net ...` | Доска задач: `tasks`, `show`, `post-task`, `claim`, `report`, `accept`, `revise`, `sync`, `id`; см. [руководство по доске](../../docs/BOARD.md) |
| `skynet-agent config show` / `set КЛЮЧ ЗНАЧЕНИЕ` | Настройки |
| `skynet-agent update` | Поставить новейшую подписанную версию сейчас |
| `skynet-agent selftest [--online]` | Проверить устройство, установленные файлы и подписи |
| `skynet-agent autostart enable` / `disable` | Запускаться при входе или нет |
| `skynet-agent uninstall --yes` | Выключить автозапуск и остановиться; затем удалите папку агента |

## Настройки

| Настройка | По умолчанию | Смысл |
|---|---|---|
| `workers` | 1 | Сколько заданий считать одновременно; каждое занимает примерно одно ядро процессора |
| `run_on_battery` | false | Работать от батареи |
| `poll_minutes` | 30 | Как часто заглядывать в репозиторий |
| `update` | auto | `auto` ставит подписанные обновления, `notify` только сообщает о них, `off` их не замечает. Пауза, объявленная ведущими, действует в любом режиме |
| `submit` | auto | `auto` публикует результаты, `manual` оставляет их в «исходящих» |
| `submit_via` | net | `net`: подписанные записи, без учётной записи; `github`: комментарии под вашей учётной записью GitHub |
| `max_task_minutes` | 120 | Сколько может длиться одна порция работы |
| `batch_minutes` | 60 | При `submit_via github`: результаты одного задания публикуются вместе, не чаще одного комментария за столько минут |
| `max_submissions_per_day` | 48 | При `submit_via github`: сколько комментариев в сутки публикуется с этого устройства |
| `report_platform` | true | Добавлять к результату грубую метку вида `windows-amd64-py3.12` |
| `ai.enabled` | false | Режим ИИ, см. ниже |

Пример: `skynet-agent config set workers 4`.

## По желанию: отвечать на вопросы своей локальной ИИ-моделью

Если вы запускаете у себя открытую модель (например, через Ollama, сервер llama.cpp или
LM Studio), агент может передавать ей исследовательские вопросы из списка заданий и публиковать
ответы. По умолчанию это выключено, режим опытный.

```sh
skynet-agent ai                               # показывает локальный сервер и модель, которую он будет использовать
skynet-agent config set ai.enabled true
```

- Агент не скачивает и не запускает модель. Он обращается только к серверу на вашем
  компьютере, пока вы не включите `ai.allow_remote`.
- Вопрос и документы, которые он цитирует, взяты из подписанного списка; каждый документ
  сверяется с отпечатком, прежде чем его увидит модель.
- Каждый ответ ждёт в «исходящих», пока вы его не посмотрите: `skynet-agent outbox show ИМЯ`,
  затем `skynet-agent outbox approve ИМЯ`. Публиковать без просмотра:
  `skynet-agent config set ai.review_before_submit false`.
- Ответы публикуются как машинные и никем не проверенные.

## Безопасность, честно

- **Обновления и списки заданий подписаны** (Ed25519). Агент принимает их, только если подпись
  соответствует ключу выпуска, зашитому в установленную копию, номер версии больше текущего
  и каждый файл совпадает со своим SHA-256. Скачивание с зеркала или по плохому соединению
  этого не меняет.
- **Задания — это данные, а не программы.** Новые виды расчётов приходят только внутри
  подписанной версии, как читаемый исходный текст на Python в
  [`skynet_agent/kernels`](../../agent/skynet_agent/kernels).
- **Агент работает в изолированном режиме Python**, каждая порция работы идёт в отдельном
  процессе с низким приоритетом и пределом времени.
- **Если новая версия не запускается**, запускатель возвращает прежнюю и запоминает, что эту
  версию ставить не надо.
- **Ключ вашего устройства** — это обычный файл в папке агента. Кто его скопирует, сможет
  подписывать от имени этого устройства; сохраните копию, если хотите сохранить своё имя
  на доске после переустановки.
- **Чему приходится доверять.** Держатель ключа выпуска может доставить программу на все
  установленные агенты. На исследовательском этапе ключ у ведущих проекта. Если вы не хотите
  автоматических обновлений, выполните `skynet-agent config set update notify` и обновляйтесь
  вручную, прочитав изменения. Самая первая установка доверяет соединению HTTPS с GitHub.
  В сети SkyNet такого ключа быть не должно; агент — инструмент исследования и сам требованиям
  SkyNet пока не удовлетворяет. Подробности и таблица угроз:
  [docs/RESEARCH_AGENT.md](../../docs/RESEARCH_AGENT.md).

## Приватность

Агент скачивает открытые файлы этого репозитория (GitHub видит ваш IP-адрес, как при любом
посещении) и отправляет результаты и записи доски задач ретрансляторам и узлам, перечисленным
в агенте (они тоже видят ваш IP-адрес). В результате есть имя задания, номер порции,
посчитанные числа, время расчёта и, если вы не выключили `report_platform`, грубая метка
платформы. Он публичен и подписан ключом этого устройства. Сведения о ваших файлах, сети
и оборудовании не собираются.

## Чего это стоит вам

Электричество на одно занятое ядро процессора по умолчанию, с низшим приоритетом, так что
другие программы не замедляются. На телефоне батарея не расходуется, пока вы этого не
разрешите; держите телефон на зарядке.

## Удаление

При установке через EXE-установщик выберите в меню «Пуск» **SkyNet Agent → Uninstall**. Программа удаления по умолчанию сохраняет ключ устройства и неотправленные результаты. Чтобы удалить и их, отметьте флажок удаления данных. При установке из командной строки выполните следующую команду.

```sh
skynet-agent uninstall --yes
```

Затем удалите папку агента. Больше на вашем компьютере ничего не менялось.

## Если что-то не так

- **«no valid signature from a trusted release key»**: скачанный файл не тот, что подписали
  ведущие. Агент его отвергает и продолжает работать с тем, что есть. Если это повторяется
  несколько дней, посмотрите задачи репозитория.
- **`CERTIFICATE_VERIFY_FAILED` в macOS** с Python с сайта python.org: агент сам пробует
  системный файл сертификатов. Если ошибка осталась, запустите
  `Install Certificates.command`, который идёт с этим Python.
- **Python из Microsoft Store (Windows)** видит собственную копию `AppData` и реестра.
  С ним папка агента — `SkyNetAgent` в папке профиля, а автозапуск добавляется вручную:
  как именно, пишет команда `skynet-agent autostart enable`. На настоящем устройстве
  этот случай ещё не проверен.
- **Результаты остаются в «исходящих»**: выполните `skynet-agent status`. При `submit_via net`
  ретрансляторы или узлы были недоступны (брандмауэр?); при `submit_via github` обычно
  не хватает `gh auth login`.
- **Android останавливает агент в фоне**: выполните в Termux `termux-wake-lock` и исключите
  Termux из экономии батареи.

## Что проверено

Набор тестов ([`tests/`](../../agent/tests)) покрывает подписи, обновление, откат, задания,
публикацию, подписанные записи, доску задач, полный узел и сквозной прогон и запускается
автоматически в Windows, Linux и macOS при каждом изменении (вкладка Actions репозитория).
Вручную агент проверен в Windows 11. На настоящем устройстве пока не проверены:
Android (Termux) и автозапуск в macOS, Linux и Android. Если у вас что-то не работает,
откройте, пожалуйста, задачу.
