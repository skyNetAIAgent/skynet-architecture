# Исследовательский агент SkyNet для Android (опытный)

[English](../../android/README.md) · [中文](../zh/ANDROID.md) · [Español](../es/ANDROID.md) · [Français](../fr/ANDROID.md) · [Deutsch](../de/ANDROID.md) · [Italiano](../it/ANDROID.md) · **Русский** · [Português](../pt/ANDROID.md) · [العربية](../ar/ANDROID.md)

Приложение для Android, которое содержит тот же [исследовательский агент](../../agent/README.md),
что и настольная версия. Оно для тех, кто не хочет настраивать Termux: установите один файл
и нажмите «Start». На этом этапе вознаграждений нет.

**Состояние: опытное.** 22 ноября 2026 года приложение проверено на эмуляторе Android 14
(x86_64) с локальным тестовым репозиторием, подписанным тестовым ключом: оно установилось,
запустилось, проверило подписи, без ошибок посчитало все 7 порций тестовых заданий, ждало,
пока эмулятор был не на зарядке, продолжало работать в фоне, сохранило токен и обратилось
с ним к настоящему API GitHub, а затем остановилось и снова запустилось с сохранённым
состоянием. Сборка только для ARM (`arm64-v8a`) сделала то же самое на этом эмуляторе через
ARM-трансляцию. Её часть на Python также проходит тесты на компьютере.
**На настоящем телефоне приложение ещё не проверялось**: ни на Android 7–13, ни в длительных
запусках, ни против режимов энергосбережения производителей телефонов. Запуск агента в
[Termux](../../agent/README.md#install) остаётся другим способом.

## Для участников

1. Скачайте `skynet-agent.apk` со страницы
   [Releases](https://github.com/skyNetAIAgent/skynet-architecture/releases).
2. Откройте файл. Android попросит разрешить установку приложений из вашего браузера или
   файлового менеджера.
3. Откройте «SkyNet Agent» и нажмите **Start**. Постоянное уведомление показывает, что
   приложение работает.

Что нужно знать:

- Оно работает только пока устройство заряжается, если вы не отметите «Также работать от
  батареи». Зарядка проверяется между порциями работы: начатая порция (обычно меньше минуты)
  доводится до конца, даже если вы отключите устройство от зарядки.
- После перезапуска устройства оно не запускается само: откройте приложение и снова нажмите
  «Start».
- На Android 13 и новее, если вы отклоните уведомления, приложение всё равно работает;
  Android тогда показывает его только в списке запущенных приложений.
- Для публикации результатов нужен токен GitHub: в GitHub откройте Настройки → Настройки
  разработчика → Персональные токены доступа, создайте токен, который может писать задачи
  публичных репозиториев, и вставьте его в приложение. Токен хранится только внутри
  приложения. Без токена результаты ждут на устройстве (до 300, после чего приложение
  перестаёт считать).
- Android 7.0 или новее, 64-битное устройство, около 40 МБ.
- Дополнительный режим ИИ в приложении недоступен.
- Чтобы удалить его, удалите приложение; больше на устройстве ничего не остаётся.

## Чем оно отличается от агента на компьютере

| | На компьютере | Приложение Android |
|---|---|---|
| Код агента | `agent/skynet_agent` | тот же пакет, собранный в APK |
| Работа | отдельные процессы с низким приоритетом | по одной порции за раз внутри фонового процесса приложения |
| Предел времени | рабочий процесс завершается | сторож завершает фоновый процесс; Android перезапускает его, а задание остаётся более быстрым устройствам |
| Обновления агента | подписанный выпуск из репозитория | тот же подписанный выпуск, проверяемый кодом, встроенным в APK: подпись, каждый файл, отсутствие файлов вне подписанного списка, никогда не ниже наибольшего выпуска, который уже работал здесь. Новому выпуску даётся три попытки связаться с репозиторием; иначе приложение возвращается к встроенному коду |
| Само приложение | запускатель и установщик | меняется только с новым APK |
| Публикация | вход через GitHub CLI | токен, вставленный в приложение |

Честные границы. APK подписан ключом, который хранится у сопровождающих проекта; Android принимает
обновление приложения, только если оно подписано тем же ключом. Ключ выпуска (для кода агента
и списков заданий) и этот ключ APK — две единые точки доверия, которых в целевой сети SkyNet
быть не должно. Приложение загружает подписанный код Python во время работы, что правила
Google Play не допускают, поэтому оно распространяется как файл.

## Соберите сами

Вам нужны JDK 17, Android SDK (platform 34, build-tools 34), Gradle 8.7 и Python 3.12 на
компьютере для сборки.

```sh
cd android
gradle assembleRelease
```

Результат — `app/build/outputs/apk/release/app-release-unsigned.apk`. Подпишите его своим
ключом (`zipalign`, затем `apksigner sign`), прежде чем устанавливать. APK, который вы
подписали сами, нельзя установить поверх APK проекта, и наоборот.

Собирайте приложение только из коммита, в котором `agent/skynet_agent/trust.py` указывает
ключ выпуска: агент без ключа выпуска не принимает заданий. В этом случае сборка выпуска
останавливается с ошибкой; `-PallowNoReleaseKey` всё равно собирает такой APK, только для
тестов.

Часть приложения на Python — [`app/src/main/python/skynet_android.py`](../../android/app/src/main/python/skynet_android.py).
Она проверяется на компьютере тестом [`agent/tests/test_android_glue.py`](../../agent/tests/test_android_glue.py).
Python встроен через [Chaquopy](https://chaquo.com/chaquopy/) (лицензия MIT).
